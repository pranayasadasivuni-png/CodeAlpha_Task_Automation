CodeAlpha Task 3: Task Automation with Python

Project Overview

This project automates the task of moving JPG image files from one folder to another using Python.

Features

- Automatically creates source and destination folders.
- Identifies JPG files in the source folder.
- Moves JPG files to the destination folder.
- Displays the number of files moved.

Technologies Used

- Python
- "os" module
- "shutil" module

How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Run "python task_automation.py" in the terminal.
4. Place JPG images inside the "source_images" folder.
5. Check the "jpg_images" folder for the moved files.

Learning Outcomes

- File and folder handling
- Working with Python modules
- Loops and conditional statements
- Automating repetitive tasks
